SIMPLE DB 0.1.1 — PRODUCT REQUIREMENTS

Language and execution
- All extension code and tests are written in JavaScript.
- TypeScript, tsconfig.json, and a TypeScript compilation step are not used.
- F5 loads src/extension.js directly.

Required database engines
- SQLite.
- PostgreSQL.
- MySQL.
- SQL Server.
- Oracle.

Connections
- Create, edit, test, and delete connections.
- Support multiple connections per engine and multiple connected engines at the same time.
- Store passwords in VS Code SecretStorage.
- Support SSL/TLS/encryption and timeouts as appropriate for each engine.

Exploration
- Databases and schemas where exposed by the engine.
- Tables, views, and columns.
- Materialized views where available.
- Procedures and functions.
- Oracle packages.
- Indexes, triggers, sequences, and types where available.
- Synonyms in Oracle/SQL Server and MySQL events.
- Show definitions/DDL and prepare CREATE, ALTER, and DROP scripts.

Editor and execution
- Regular VS Code SQL documents linked to a profile/database/schema.
- Execute the entire document, a selection, or the statement at the cursor.
- SELECT, INSERT, UPDATE, DELETE, MERGE, and any DML supported by the engine.
- CREATE, ALTER, DROP, TRUNCATE, and any other DDL supported by the engine.
- PostgreSQL dollar quotes, MySQL DELIMITER, SQL Server GO, Oracle PL/SQL and `/` terminator, SQLite triggers.
- Stop document execution at the first error and select the failed block.

Transactions and cancellation
- Auto-commit outside an explicit transaction.
- Per-editor BEGIN, COMMIT, and ROLLBACK.
- Reserve the physical connection for the duration of a transaction.
- ROLLBACK when closing an editor/disconnecting with an open transaction.
- Cancellation through the driver's native mechanism.
- Configurable timeout per profile.

Results
- Table output, types, NULL, multiple result sets, retrieved/affected rows, and duration.
- Copy a cell, row, or selection.
- Export CSV, JSON, and XLSX without executing the query again.
- Configurable local history.

Row policy
- simpleDb.maxRows = 0 by default: NO LIMIT.
- Users can choose a limit greater than zero when needed.
- simpleDb.resultPageSize controls storage/display pages, not the total number of rows.
- Simple DB DOES NOT inject TOP, LIMIT, or FETCH into user SQL.

Protections
- Configurable confirmation for DROP/TRUNCATE.
- Configurable warning for UPDATE/DELETE without WHERE.
- Generated destructive scripts open in the editor and are never executed automatically.
